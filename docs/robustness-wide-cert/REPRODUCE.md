# Reproduction

Read PLAN.md first; each implementation stage and its negative results are
recorded there. RESULTS.md is generated by
`python benchmarks/report_robustness_wide_cert.py` after the audit.

1. Build/test the current production source with `cargo test --locked --release
   --workspace --all-features`, `cargo clippy --locked --workspace --all-targets
   --all-features -- -D warnings`, `cargo fmt --all --check`.
2. Build Python with `maturin build --locked --release`; install its wheel, run
   `python -m pytest -q`. Core/native Rust checks require no Python dependency.
3. Reconstruct 0.20 from the prior archive or the retained original history,
   ending at original revision bf5bcb0565d9411cfa812b668c0a917975af019c.
   Current work began from a losslessly restored source snapshot (local root
   commit 367af0b); new staged patches are under history/robustness-wide-cert.
4. For the isolated old HiGHS adapter, run
   `python benchmarks/reference/bootstrap_sources.py`. Build the current shared
   harness against it using `benchmarks/build_packing_references.py`, passing
   the 0.20 source as `--baseline-repo`. The production workspace never gains a
   HiGHS dependency. Copy the old reference Cargo.lock into the generated harness
   before building if identical transitive benchmark dependencies are desired.
5. Build `benchmarks/Cargo.toml` in both native sources. Compare using
   `compare_three.py --rounds 3` for the full earlier standard suite and
   `compare_packing_mip.py --rounds 5` for extended fixtures. Use `--holdout`
   for the earlier seed set, explicit `--case` for the previous-fresh and new
   holdouts in the JSON summaries, and `--public-corpus docs/packing-mip/corpus`.
   `compare_large.py --rounds 3` checks irregular4096.
6. Build both benchmark sources with `--features basis-replay`; run
   `replay_compare.py --rounds 2 --corpus docs/irregular-lu/corpus` to obtain
   84 retained records across 21 inputs and two builds. `kernel-profile` adds
   exclusive timers; normal timings use builds without instrumentation.
   `LPIP_TRACE_SIMPLEX=1` enables phase/restart diagnostics only in such builds.
7. Run oracle_worker.py on unchanged docs/performance-ten/data/oracle-inputs.json
   for default, --variant ft, --no-fixing, --variant refactor1 --suite exact,
   --variant workers4 --suite components. Run check_bounds.py with the Python
   native backend. The permanent prepared-bound Rust regression independently
   computes 5120 exact i128 Lagrangian values.
8. Place outputs under docs/robustness-wide-cert/data using the included names;
   run `python benchmarks/audit_robustness_wide_cert.py` and then the report script.

Timing runs were sequential, after compilation and correctness gates; each uses
one discarded round and process warmups. Retain every failure and unfavorable
case. The shared host provides no timing guarantee or application readiness
claim. Input fingerprints, acceptance tolerances and prior adjudications must
not be changed to make a candidate pass.
